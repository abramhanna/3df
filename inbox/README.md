# Inbox

Upload Word files (.docx) here to convert them. In Google Docs: File → Download → Microsoft Word (.docx).

1. On github.com, open this `inbox` folder and choose **Add file → Upload files**.
2. Drop in one or more .docx files and click **Commit changes**.
3. Wait 2–3 minutes. Each file gets its own folder in [`outbox`](../outbox) with:
   - `.html`: web page that opens on any device and moves
   - `.pdf`: for printing and filing
   - `.epub`: ebook for Apple Books and Google Play Books
   - `.3df`: the master copy
   - `REPORT.md`: what was made, and any warnings

Progress is shown on the **Actions** tab. To make a GIF draggable, start its alt text with `[drag]` in Google Docs.
